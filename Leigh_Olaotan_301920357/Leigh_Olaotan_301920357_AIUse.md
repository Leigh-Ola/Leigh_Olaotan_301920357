# AI Use Declaration and Student Confirmation

## Tools and assistance

AI helped me with designing and testing this code base. It also helped to examine the assessment requirements that I had. It helped me critique the shop model and the scripts and tests and the documentation and the final summary.

It also assisted me with diagnosing errors, formatting, researching for my sources, the comparison of results and helped examine the completed P1 work.

## Recorded tests

I compared the SQL schema with the design and executed valid and invalid operations and also compared the data before and after to each other, before and after the tests to each other. I also repeated those tests in isolated databases. Also note that the benchmarks in this codebase compares those same results before and after an index changes.

The concurrency tests records include session weights and the final stock. There are also MongoDB tests that compare document types, queries, results, validator rules and the P1 business records and finally the original output of each of these actions remains within each component of this portfolio.

## Student input

I personally selected the idea to be a small online shop case and I decided on the database schema, the stages in which this work are to be done in and decided on how the documentation is to be written and structured everywhere. Additionally, I also directed the work and requested implementation and inspection stages from AI. I guided each one with a combination of my own manual work and AI assisted changes and reviews.

Finally before submission I examined all of the scripts and results myself.
