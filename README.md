# MIT 8103 Advanced Database Systems Portfolio

**Olaotan Leigh | Student ID 301920357 | 2026/2027, first semester**

Harbour Office Supplies is a fictional Nigerian online stationery shop with one stockroom. PostgreSQL stores customer, product, order, stock and payment records. MongoDB stores order events. All business data is fictional.

Start with the [portfolio README](Leigh_Olaotan_301920357/Leigh_Olaotan_301920357_README.md) or the [three-page summary](Leigh_Olaotan_301920357/Leigh_Olaotan_301920357_FinalSummary.pdf).

## Portfolio components

| Component | Work and evidence |
| --- | --- |
| [P1: Database design](Leigh_Olaotan_301920357/portfolio-1-database-design/Leigh_Olaotan_301920357_P1_README.md) | Case study, five tables, ER diagram, normalisation, fictional data and constraint tests. |
| [P2: Queries and performance](Leigh_Olaotan_301920357/portfolio-2-query-optimisation/Leigh_Olaotan_301920357_P2_README.md) | Six business queries, execution plans, measured timings and an index comparison. |
| [P3: Transactions and concurrency](Leigh_Olaotan_301920357/portfolio-3-transactions-concurrency/Leigh_Olaotan_301920357_P3_README.md) | Commit, rollback, controlled order operations and tests with independent sessions. |
| [P4: NoSQL model](Leigh_Olaotan_301920357/portfolio-4-nosql/Leigh_Olaotan_301920357_P4_README.md) | MongoDB event documents, queries, validation rules and test results. |
| [P5: Distributed databases](Leigh_Olaotan_301920357/portfolio-5-distributed-cloud/Leigh_Olaotan_301920357_P5_README.md) | Proposed architecture, replication, consistency, availability, sharding and recovery. |

P1 to P5 mean Portfolio 1 to Portfolio 5. P1 to P4 contain executed local work. P5 is a design discussion. Its proposed system has not been deployed.
